Review schedule

These are daily limits, not per-session ones: once a day's new words are introduced, the review page says so instead of handing you an endless supply. Meeting a batch again tomorrow is what moves it into memory. The end-of-session screen can always pull more forward.

AI features

The news digest, the tutor, and English backs for sentences the dictionary cannot translate are written by a model on your own API key. Paste an OpenAI key (or a fal.ai key) below — one key turns on all three. It is stored in this browser only, sent with those requests so the sync server can forward them to the provider, and never stored on the server. Everything else — the hover popup, the dictionary, saving, flashcards, review — works with no key at all.

Typical cost is well under a dollar a month: a news digest is one call (cached 12 hours), the tutor and translation are short calls with hourly caps. Leave it empty to keep everything off.

Phone sync

Review your flashcards on your phone. Cards sync through a small server you control (a free Cloudflare Worker — see worker/ in the project). No account needed: your browser generates a private pairing code.

Scan this code with your phone's camera to open the review app already paired. Anyone with this code can read and change your cards, so treat it like a password.

Saved library — words and full example sentences saved for review, with dates and save counts.

Review — spaced-repetition flashcards (SM-2 style) for your saved words, with example sentences on the back.

HSK study guides — a guide for every level 1-9 (grammar, vocabulary, a reading passage, common mistakes), hoverable like any other page, with a tutor you can point at whatever you highlight.
