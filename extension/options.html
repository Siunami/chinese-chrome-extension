AI features

The news digest, the tutor, and English backs for sentences the dictionary cannot translate are written by a model on your own API key. Paste an OpenAI key (or a fal.ai key) below — one key turns on all three. It is stored in this browser only, sent with those requests so the sync server can forward them to the provider, and never stored on the server. Everything else — the hover popup, the dictionary, saving, flashcards, review — works with no key at all.

Typical cost is well under a dollar a month: a news digest is one call (cached 12 hours), the tutor and translation are short calls with hourly caps. Leave it empty to keep everything off.

Phone sync

Review your flashcards on your phone. Cards sync through a small Cloudflare Worker. No account needed: your browser generates a private pairing code.

Scan this code with your phone's camera to open the review app already paired. Anyone with this code can read and change your cards, so treat it like a password.

Backup

Everything this browser knows about your learning — saved cards and review progress, settings, the news archive, placement results and tutor conversations — written to one file on this computer. Chrome keeps all of it inside the extension, so uninstalling it or resetting this profile takes the lot; a backup is the only copy that survives that. Nothing is uploaded anywhere.

Leave this on to restore an install exactly as it was. Turn it off if the file is going somewhere you would not put a password — anyone holding the pairing code can read and change your cards.

Restoring merges the file's cards with the ones already on this computer, so nothing you have saved or reviewed since the backup is lost, and a card you deleted since stays deleted. Settings, news, placement results and tutor conversations are replaced by the file.
